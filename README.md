# Ochrum

Ochrum - проект AI-оркестратора, который координирует работу ИИ-агентов, моделей и инструментов в рамках одной задачи.

В качестве архитектурной основы рассматривается [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): система с модульным подходом, где возможности агента подключаются и настраиваются отдельно.

## Идея проекта

Оркестратор будет принимать задачу, выбирать подходящих агентов и инструменты, передавать им контекст и собирать результаты в единый ответ. Модули должны оставаться заменяемыми, чтобы можно было подключать разные модели и расширять систему без переработки её основы.
